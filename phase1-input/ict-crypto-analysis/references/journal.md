# سجل الصفقات وتحسين الأداء

يُقرأ هذا الملف عند تسجيل صفقة أو طلب تحليل الأداء.

اقترح على المستخدم سجل صفقات (الدخول، الوقف، الهدف، النتيجة، سبب الدخول، سكرين شوت). وبعد نحو 20 صفقة حلّله معه بالأرقام لتحديد نقاط الضعف.

عند إغلاق أي صفقة أو ذكرها، اسأل عن سعر الخروج الفعلي والحجم الفعلي والرسوم، ولا تفترض قيمًا لم يذكرها المستخدم، لأن الأرقام المفترضة تُفسد التحليل لاحقًا. سجّل كل صفقة بهذه الحقول: الدخول الفعلي، الوقف، الأهداف، سعر الخروج الفعلي، الحجم، الرسوم، النتيجة بالدولار، وسبب الدخول.
